# 提示词合集（直接复制给 AI 助手用）

方括号 [ ] 里的内容换成你自己的。

---

## 1. 写稿子：拆爆款 + 写开头
```
我要做一条 [主题] 的知识讲解短视频，目标观众是完全不懂 AI 的普通人，时长 [60] 秒左右。
先帮我分析：这个主题下，观众最常见的错误做法或误解是什么？
然后按这个结构写口播稿：
1. 前 10 秒必须出现冲突：戳中一个常见做法 / 抛出一个反常识结论 / 给出一个分级让人对号入座，三选一。
2. 一句话说清原因。
3. 给出 2–3 个能马上照做的步骤，每步都配一个生活里的例子。
4. 最后一句抛一个问题，引导大家在评论区分享自己的做法。
要求：口语化，一句话不超过 20 个字，不要“大家好我是”这类开场白，不要编造数据。
```

## 2. 把稿子转成 script.json
```
请先读 SKILL.md 的“第 1 步”，然后把下面这段稿子转成 template/script.json。
每句 3–5 秒，太长就拆句；每句选一个最合适的场景（hook / define / list / compare），
关键词要和原话一字不差；表情多用 happy 和 surprised。
稿子：
[粘贴你的稿子]
```

## 3. 做自己的卡通形象
**第一次：**
```
这是我的 [2–3] 张照片。请参考 avatar/avatar.js 的结构，把示例形象改成我的 Q 版卡通形象：
- 保留我的发型、脸型特征
- 风格：[Q 版扁平插画 / 日系 / 韩系]，头身比约 1:2
- 固定配饰：[耳机 / 眼镜 / 帽子]
- 不要腮红
一次做 4 个版本放在一张对比图里（运行 node avatar/export.js 后看 avatar/output/总览.png），我选完再细调。
```
**细调：**
```
用第 [X] 版。只改 [眼睛 / 头发 / 眉毛]，其他保持不变，再出 4 个版本对比。
[例：眼睛不要具体画，用像笑脸那样的线条；头发从“头型”和“遮不遮眉”两个方向变化]
```

## 4. 先检查静帧
```
运行 node template/render.js 2,6,10,14，然后逐张看生成的静帧：
文字有没有超出卡片、有没有被形象挡住、字幕是否完整、关键词标黄是否正确。
有问题直接改 script.json 再出一次，确认没问题再出整片。
```

## 5. 处理我的录音
```
这是我的录音：[文件路径]。我是按 script.json 的顺序读的，句子之间停顿了半秒。
请运行 python template/voice.py --rec [文件路径]，告诉我切出了几句、每句多长，
如果句数对不上，告诉我是哪一句停顿不够。
```

## 6. 加一个新画面
```
我想加一种新画面：[描述，例如“三个等级从下往上依次点亮，像游戏段位”]。
请在 template/render.js 的 SCENES 里新增一个场景，动效用 hand.js 里的手写、荧光笔、胶带这些，
元素在关键词被说出时出现（用 kwTime），并配上音效。写完先出一张静帧给我看。
```

## 7. 改动效、改风格
```
把 [某个动效] 改得 [更快 / 更慢 / 更明显]；主色从蓝色换成 [颜色]；栏目名改成 [名字]。
改完只出静帧给我确认，不要直接出整片。
```
